# Changelog — YouTube Music RVX

## v8.30.54 / Initial Release
- **Morphe CLI & Anddea Patches**: Полная адаптация патчей для YouTube Music (`com.google.android.apps.youtube.music`).
- **Фоновое воспроизведение**: Работает без подписки и при выключенном дисплее.
- **Блокировка рекламы**: Вырезание всех рекламных вставок (аудио и видео баннеры).
- **Качество звука**: Максимальный битрейт аудио по умолчанию (Always High).
- **Синхронизированные тексты песен**: Сторонние тексты песен с таймингами (Third-party lyrics) из 15+ баз данных.
- **Плавный кроссфейд (Track Crossfade)**: Бесшовное переключение треков.
- **Android Auto**: Сертификатная подмена для отображения и работы на экране автомобиля.
- **SponsorBlock**: Пропуск немузыкальных вставок и интро в клипах.
- **AMOLED Black**: Чистый черный фон темы (`#000000`).
- **Root & Non-Root поддержка**:
  - Non-Root APK для работы с GmsCore (MicroG).
  - Magisk / KernelSU / APatch модуль с технологией мгновенного bind-mount.
